# English Ladder: платформа с регистрацией и админ-панелью

Три отдельные части:

| Адрес | Что это |
|---|---|
| `/` | **Главная** (лендинг): описание, демо-карточка, тарифы, отзывы. Здесь же вход и регистрация |
| `/app` | **Приложение**: уроки A1–C2, слова, карточки, говорение, рейтинг. Только для вошедших |
| `/admin` | **Админ-панель**: кто зарегистрирован, кто что делал, управление пользователями. Только для админов |

Сервер без внешних зависимостей: Node.js 22.13+ и встроенная база SQLite. `npm install` не нужен.

## Запуск

```
node server.js          # http://localhost:3000
npm test                # 40 проверок: сервер и связка «приложение + сервер»
```

Первый зарегистрированный пользователь автоматически становится администратором
(или тот, чей e-mail указан в `ADMIN_EMAIL`). Остальные регистрируются как обычные.
Настройки (`PORT`, `ADMIN_EMAIL`, `COOKIE_SECURE`, `DB_FILE`) передаются переменными окружения, пример в `.env.example`.

## Что умеет админ-панель

* Статистика: всего пользователей, активных за 24 часа / 7 / 30 дней, новых за неделю, **зарегистрировавшихся, но ничего не сделавших**, заблокированных, админов.
* Уроки по уровням: сколько пройдено и сколько человек их проходили. Активность по дням.
* Список пользователей: поиск по имени и e-mail; фильтры «активны за 7 дней», «не заходили 14+ дней», «без прогресса», «заблокированные», «админы»; сортировка.
* Карточка человека: XP, уроки, слова, серия, даты регистрации и последнего входа, список пройденного и **история действий** (уроки, тесты, квизы, игры, говорение, входы).
* Действия: заблокировать / разблокировать, сделать админом / снять, сбросить пароль (временный пароль показывается один раз), удалить.
* Общая лента активности и выгрузка пользователей в CSV.

## Как это устроено

* Пароли: scrypt с индивидуальной солью. Сессии: случайный токен в cookie `HttpOnly; SameSite=Lax`, в базе хранится только его хеш, срок 30 дней.
* Защита: проверка `Origin` и `Content-Type: application/json` для всех изменяющих запросов (против CSRF), ограничение попыток входа (10 за 10 минут), лимит размера запросов, блокировка выхода за папку `public`, экранирование всех пользовательских данных в админке.
* Приложение хранит прогресс локально и каждые пару секунд отправляет на сервер; при входе с другого устройства берётся прогресс с большим XP. Прогресс разных людей в одном браузере не смешивается.
* События (прохождение урока, тест, квиз и т. д.) приложение шлёт на `/api/events`, они появляются в админке.

## Перед выходом в интернет

1. Поставьте перед сервером HTTPS (nginx/Caddy) и задайте `COOKIE_SECURE=1`.
2. Делайте резервные копии файла `data.sqlite` (вместе с `-wal` и `-shm`, либо при остановленном сервере).
3. Сервер запущен одним процессом и хранит счётчик попыток входа в памяти: за несколькими экземплярами понадобится общее хранилище.

## Чего пока нет

Подтверждения e-mail и восстановления пароля по почте (пароль сбрасывает админ), двухфакторного входа, лимита по IP за прокси
(за nginx передавайте реальный IP и доработайте `req.socket.remoteAddress`), проверки письма через ИИ и распознавания речи
(в приложении эти кнопки скрыты, их обеспечивала платформа claude.ai), блока преподавателей и оплаты.
Рейтинг и админка доверяют опыту, который присылает приложение: подделать его технически возможно.
